# Strinova offsets

This is a repository that publicly discloses the offset of the game Strinova.

### Usage

The master branch is always the latest version, go to the branch to find the version you need.
If not, use the dump tool to obtain it yourself.

There is no beginner tutorial, and beginners are not welcome.
That's it.
